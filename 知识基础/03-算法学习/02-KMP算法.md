## KMP算法
KMP算法是一种高效的**字符串匹配算法**，其核心思想是**利用匹配失败后的已知信息，避免主串指针的回退，从而将时间复杂度从暴力匹配的O(n*m)降低到O(n+m)**。

### 一、 问题背景与暴力匹配的不足
字符串匹配问题是指：给定一个**主串（文本串）S** 和一个**模式串（子串）P**，在S中查找是否包含P，并返回其起始位置。

最直观的方法是暴力匹配（Brute-Force）：将P与S的每一个可能的起始位置进行逐字符比较。一旦发现不匹配，就将模式串P向后滑动一位，主串S的指针也回退到本次匹配起始位置的下一位重新开始。

**暴力匹配的缺陷**：当发生不匹配时，主串指针会大量回退，导致许多不必要的重复比较。例如：
- 主串 S: `"abababc"`
- 模式串 P: `"ababc"`
在比较到第5个字符（S[4]的`a` vs P[4]的`c`）失败时，暴力法会让S的指针从4回退到1，P的指针回退到0重新开始。但事实上，我们已经知道S[2-4]是`"aba"`，这部分信息可以被利用。

### 二、 KMP算法的核心：前缀表（Next数组）
KMP算法通过一个预先计算的**前缀表**（常被称为`next`数组）来记录模式串自身的部分匹配信息。这个表决定了当某个字符匹配失败时，模式串应该回溯到哪个位置继续比较。

**1. 核心概念：前缀与后缀**
- **前缀**：指一个字符串除了最后一个字符以外，所有以第一个字符开头的连续子串。
- **后缀**：指一个字符串除了第一个字符以外，所有以最后一个字符结尾的连续子串。
- **最长公共前后缀长度**：对于一个字符串，其最长的、相等的前缀和后缀的长度。

**2. 前缀表的定义**
对于模式串P，其前缀表`next[i]`表示：**子串P[0...i]中，使得“长度为k的前缀”等于“长度为k的后缀”的最大的k（k < i+1）**。
简单说，`next[i]`记录了当`P[i]`与主串字符不匹配时，模式串下一个应该用来比较的字符位置是`P[next[i]]`。

**3. 前缀表的计算（以模式串 P = "ababc" 为例）**

| 下标 i | 子串 P[0...i] | 所有前缀（不含最后字符） | 所有后缀（不含第一字符） | 最长公共前后缀 | `next[i]` (长度) | 含义（失败时跳转到下标） |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 0 | `"a"` | `""` | `""` | `""` | 0 | 已无前缀可退，主串指针后移 |
| 1 | `"ab"` | `"a"` | `"b"` | `""` | 0 | 跳到P[0]比较 |
| 2 | `"aba"` | `"a", "ab"` | `"ba", "a"` | `"a"` | 1 | 跳到P[1]比较 |
| 3 | `"abab"` | `"a","ab","aba"` | `"bab","ab","b"` | `"ab"` | 2 | 跳到P[2]比较 |
| 4 | `"ababc"` | `"a","ab","aba","abab"` | `"babc","abc","bc","c"` | `""` | 0 | 跳到P[0]比较 |

因此，对于 P = `"ababc"`，计算得到的前缀表（`next`数组）为：`[0, 0, 1, 2, 0]`。

**4. 前缀表的构建算法（程序化）**
这是一个自匹配的过程：
- 定义两个指针：`i`指向当前子串的末尾（也是`next`数组的索引），`j`指向前缀的末尾位置（也代表当前最长公共前后缀的长度）。
- 初始化：`next[0] = 0`, `j = 0`, `i = 1`。
- 遍历`i`从1到模式串末尾：
    - **情况1**：`P[i] == P[j]`。前后缀匹配长度增加，`j++`，然后`next[i] = j`，`i++`。
    - **情况2**：`P[i] != P[j]`。说明当前前缀不匹配，需要回退`j`到`next[j-1]`的位置（即上一个匹配成功的前缀末尾）继续尝试匹配，直到`j==0`或匹配成功。
    - 如果`j==0`且仍不匹配，则`next[i]=0`，`i++`。

### 三、 KMP匹配流程
使用上面计算好的前缀表`next`，进行主串S和模式串P的匹配。
1. 初始化两个指针：`i`指向主串S的当前位置，`j`指向模式串P的当前位置。
2. 循环比较`S[i]`和`P[j]`：
    - 如果`S[i] == P[j]`，则`i++`, `j++`。
    - 如果`j == len(P)`，说明匹配成功，返回位置`i - j`。
    - 如果`S[i] != P[j]`：
        - 如果`j > 0`，则利用前缀表将`j`回退到`next[j-1]`（**注意：主串指针`i`不动！**）。
        - 如果`j == 0`，则无法回退，主串指针`i`前进一位。
3. 循环结束，若未找到则返回-1。

**示例：S = "abababc", P = "ababc", next = [0,0,1,2,0]**
1. `i=0,j=0`: S[0]`a`=P[0]`a` -> i=1,j=1
2. `i=1,j=1`: S[1]`b`=P[1]`b` -> i=2,j=2
3. `i=2,j=2`: S[2]`a`=P[2]`a` -> i=3,j=3
4. `i=3,j=3`: S[3]`b`=P[3]`b` -> i=4,j=4
5. `i=4,j=4`: S[4]`a` != P[4]`c` -> **不匹配**。`j=4>0`，`j`回退到`next[4-1]=next[3]=2`。
6. `i=4,j=2`: S[4]`a`=P[2]`a` -> i=5,j=3
7. `i=5,j=3`: S[5]`b`=P[3]`b` -> i=6,j=4
8. `i=6,j=4`: S[6]`c`=P[4]`c` -> i=7,j=5
9. `j=5 == len(P)`，匹配成功，起始位置为`i - j = 7 - 5 = 2`。

可以看到，在整个过程中，主串指针`i`从未回退，一直从0递增到6，这是KMP高效的关键。

### 四、 算法优势与应用
- **时间复杂度**：构建前缀表O(m)，匹配过程O(n)，总体**O(n+m)**。
- **空间复杂度**：需要额外的O(m)空间存储前缀表。
- **核心优势**：避免了主串指针的回退，特别适合处理在主串中多次查找同一模式串，或主串是流数据无法回退的场景。
- **典型应用**：文本编辑器中的查找功能、搜索引擎的关键词匹配、生物信息学的DNA序列比对、网络入侵检测系统中的特征匹配等。

### 总结
KMP算法的精髓在于**通过前缀表记录了模式串自身的结构信息，在匹配失败时智能地滑动模式串，避免了主串指针的回退和大量无意义的重复比较**。理解“最长公共前后缀”和前缀表的构建是掌握KMP的关键。

### 简单代码实现
```C++
// 找到主串S中模式串P的第一个匹配位置
int strStr(string s, string p)
{
    int n = s.size();
    int m = p.size();
    if (m == 0) return 0;

    vector<int> next(m);
    for(int i = 1, j =0; i < m; i++)
    {
        while(j > 0 && p[i] != p[j])
        {
            j = next[j-1];
        }
        if(p[i] == p[j])
        {
            j++;
        }
        next[i] = j;
    }
    for(int i = 0, j = 0; i < n; i++)
    {
        while(j > 0 && s[i] != p[j])
        {
            j = next[j-1];
        }
        if(s[i] == p[j])
        {
            j++;
        }
        if(j == m)
        {
            return i - m + 1;
        }
    }
    return -1;
}
```
